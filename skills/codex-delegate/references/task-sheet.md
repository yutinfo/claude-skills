```text
# ใบงาน NN — <ชื่อสั้น>
ผู้รับงาน: Codex · โมเดล: gpt-6.2-sol / medium · sandbox: workspace-write

เป้าหมาย — [พฤติกรรมที่ผู้ใช้ควรเห็น]
หลักฐาน — [ไฟล์/ฟังก์ชัน/คำสั่งที่ล้ม + error ที่เกี่ยวข้อง]
ขอบเขต — แก้ได้: [ไฟล์]; ห้ามแตะ: [ไฟล์/API/ข้อมูลที่ต้องรักษา]
เกณฑ์ผ่าน — [อินพุต → ผลที่คาด], [กรณีขอบ]
การตรวจ — รัน [เทสต์เจาะจุด] แล้วรัน [เทสต์ชุดที่เกี่ยว]
ส่งมอบ — สรุปไฟล์ที่แก้ เหตุผล คำสั่งที่รัน และผลทดสอบจริง; ยังไม่ต้อง commit
```

## ตัวอย่างดี (แก้บั๊ก)

```text
แก้ formatPrice ใน format-price.mjs ตอนนี้ราคา 0 แสดงเป็น "—"
ผลที่ต้องการ: formatPrice(0) → "0.00 THB", formatPrice(0, 'USD') → "0.00 USD"
รักษาพฤติกรรมเดิมของจำนวนทั่วไป, null, undefined, NaN

เพิ่ม regression test 1 รายการใน format-price.test.mjs ตรวจทั้งสองสกุลเงิน แล้วรัน node --test
ให้เห็นกรณีศูนย์ล้มก่อนแก้ จากนั้นแก้โค้ดให้น้อยที่สุดแล้วรันอีกครั้ง
แก้เฉพาะสองไฟล์นี้ สรุปผลเทสต์ก่อน/หลังแก้ ยังไม่ต้อง commit
```

ทำไมดี: ระบุไฟล์และฟังก์ชัน, มีค่าคาดหวังเป็นตัวเลขจริง, บอกสิ่งที่ต้องรักษา, บังคับให้มีหลักฐาน (ล้มก่อน/ผ่านหลัง), จำกัดไฟล์

## ตัวอย่างแย่

```text
ช่วยดูโปรเจกต์นี้หน่อย ราคามันแสดงแปลก ๆ แก้ให้ดีขึ้น แล้วจัดโค้ดให้สวยด้วย
```

ทำไมแย่: Codex ต้องสำรวจทั้ง repo (เปลืองโทเคน), ไม่รู้ว่า "แปลก" คืออะไร, รวมงานแก้บั๊กกับ refactor ทำให้ diff ใหญ่ตรวจยาก, ไม่มีเกณฑ์ผ่าน

## ตัวอย่าง: งาน UI ที่ Codex ตรวจด้วยตาไม่ได้

- แนบภาพหน้าจอจริง (`--image`) พร้อมบอกชื่อภาพตามลำดับในข้อความ
- ระบุค่าจริง: "ปุ่มหลักพื้น #6F4E37 ตัวอักษรขาว สูง 52px; disabled พื้น #EFE8DE ตัวอักษร #B5A89C"
- บอกวิธีทำให้เกิดบั๊กพร้อมตัวเลขที่วัดได้: "`#member-phone` y=657–701 ทับ `#cart-totals` เริ่ม y=647 ที่ 1440×900"
- สั่งให้เขียนผลเป็นรายข้อลง log แล้ว Claude ตรวจในเบราว์เซอร์เองหลังจบ

## ตัวอย่าง: แยกรีวิวอิสระ 2 ฝั่งแล้ว merge

1. ใบงานรีวิวให้ Codex: `-s workspace-write` แต่เขียนได้เฉพาะ `docs/review/codex-review.md`, ห้ามอ่านรีวิวของ Claude
2. Claude เขียนรีวิวของตัวเองให้เสร็จ **ก่อน** เปิดอ่านของ Codex
3. รวมเป็น `merged-review.md`: ตัดข้อที่ตรวจแล้วไม่จริง, ตัดสินข้อขัดแย้งพร้อมเหตุผล, จัดลำดับ P1/P2/P3
4. ใบงานแก้รอบเดียวอ้างอิง merged-review
